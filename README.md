# محاميك

محامٍ ذكي في جيب الفرد: يمشي معه خطوة بخطوة من أول سؤال حتى تنفيذ الحكم، ويتابع الجلسات والمحاضر والمذكرات والأحكام والاعتراض. مبني على ما وصل إليه «الرائد للمحاماة» من أنظمة وسوابق.

تطبيق Expo (SDK 58، TypeScript، expo-router) يعمل على أندرويد وiOS، والأولوية أندرويد. الواجهة عربية RTL بالكامل بهوية «الديوان».

## التشغيل

```bash
npm install
npx expo start          # ثم اضغط a لأندرويد، أو امسح الرمز بتطبيق Expo Go
```

- بدون `EXPO_PUBLIC_API_URL` يعمل ببيانات تجريبية. رمز الدخول التجريبي: `1234`.
- لربط الخلفية: انسخ `.env.example` إلى `.env` واضبط العنوان.
- في Expo Go يُطلب RTL من النظام عند أول تشغيل، ويكتمل من التشغيل الثاني. في البناء الفعلي يسري من أول تشغيل (إعداد `expo-localization`: `forcesRTL`).

بناء APK للتجربة: `npx eas-cli@latest build -p android --profile preview`

## البنية

```
src/
  app/                    الشاشات (expo-router)
    (auth)/               الترحيب، الدخول برقم الجوال، رمز التحقق
    (tabs)/               الرئيسية، قضاياي، اسأل AI، المستندات، حسابي
    case/new              معالج قضية جديدة بخمس خطوات
    case/[id]/            صفحة القضية: الرحلة، الخطوات التالية، الجلسات، المحاضر، المذكرات، السجل
      hearing/[hearingId] تجهيز الجلسة
      memo/[memoId]       المذكرة مع السند النظامي
      judgment            الحكم والاعتراض مع عدّاد المهلة
    chat, agenda, notifications
  api/
    types.ts              نماذج البيانات (العقد بين التطبيق والخلفية)
    services/contracts.ts واجهات الخدمات
    services/http.ts      التطبيق الحقيقي: REST تحت /api/v1 حسب وثيقة البنية
    mock/                 تطبيق تجريبي في الذاكرة
  features/               استعلامات React Query والمسميات العربية
  components/ui           المكونات العامة (نص، زر، بطاقة، وسم AI...)
  components/case         مكونات القضية (شريط الرحلة، بطاقة السند، تنبيه المهلة...)
  theme/                  رموز التصميم: كل الألوان والخطوط من هنا
```

## قواعد

- وسم الذكاء الاصطناعي كلمة **AI** في كبسولة نحاسية، بلا أيقونة نجوم.
- كل نص عبر مكوّن `Text` من `components/ui` لضمان الخط والمحاذاة.
- لا ألوان مباشرة في الشاشات: من `useTheme()` فقط.
- المراجع النظامية في البيانات التجريبية أمثلة توضيحية؛ المرجع المعتمد هو محرك الرائد.
